`deploy/argocd/values.yaml` is a compatibility **symlink**, not a second values
file. Old readers get identical canonical bytes. Do not replace it with a copy.
Empty-cluster bootstrap still requires all other existing security prerequisites;
the opt-in is not authorization to reinstall a running release or reset OIDC.

## Offline contract maintenance

```
uv sync --locked
uv run python scripts/check_infrastructure_contracts.py
uv run python -m unittest discover -s tests -p test_infrastructure_contracts.py
```

The contract validates mesh/inventory membership/addresses and nine registered
issuer consumers. It does not prove live Service IP/UID or network reachability.
On a reviewed endpoint change: confirm the actual Service and network path first,
edit the canonical JSON, then run `scripts/check_infrastructure_contracts.py
--write`. Only registered IP scalars are regenerated, retaining comments and
remaining YAML. Review Git diff and renders before publishing. There is no
runtime generator/controller dependency, no automatic production mutation and
no TLS workaround. A new consumer must be explicitly registered and tested.

Quality Graph node `infrastructure-contracts` installs SHA-pinned setup-helm
with Helm3.19.0, uses locked PyYAML, and runs the explicit offline suite. Generated
workflows come from `qg.yaml`; use `uv run qg generate` and `uv run qg validate`.
Local success is not a claim that remote CI has already run or branch protection
has been changed. No broad test discovery against production is introduced.

## Operational scripts lifecycle

| Script | Lifecycle | Safety boundary |
|---|---|---|
| `check_infrastructure_contracts.py` | Active offline check/generator | Check default; `--write` only tracked configuration, no Kubernetes/SSH/network. |
| `check_target_placement.py` | Active read-only convergence check | Requires positive desired replicas, observed generation, exact target node, Ready container statuses and Deployment/ReplicaSet ownership. No mutation. |
| `vm105-stateless-handoff.py` | Historical one-way maintenance | Already-on-socrat-5 refusal; pause/restore Service, exact original worker idle checks. Not a deploy entrypoint. |
| `vm105-spi-idle-handoff.py` | Historical one-way maintenance | Refuses non-original placement; full owner/lease drain and targeted reconcile hold; never force idle or replay. |
| `socrat5-storage-guard.py` | Active host storage prerequisite | Review role/invocation and expected mounts; not permission to format a disk. |
| `socrat5-otel-leaf-bootstrap.py` | Scoped credential maintenance | Existing security/secret-delivery contract; not a general deployment tool. |
| `migrate-wiki-runtime.py` | Offline migration/validation utility | Trusted private archives; stopped writer for copy/restore, no restore onto authoritative live data. |
| `wg-peer15-relay.py`, `wg-peer15-endpoint.py` | Active network mitigation | Real non-HA production dependency. Dedicated reviewed change; no shared-library rewrite or endpoint restart as cleanup. |

Other scripts have not been certified harmless by this table. Do not mass-delete
recovery tools or run them to discover their purpose. Follow individual runbooks;
retire by fail-closed guards and documentation before physical removal.
