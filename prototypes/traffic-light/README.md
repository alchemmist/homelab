# Traffic Light native visualization previews

Four complete, importable Grafana dashboards generated by:

```sh
python3 scripts/build-traffic-light-variants.py
```

Import `tmp-1.json` through `tmp-4.json` in Grafana (Dashboards → New → Import).
Each has a distinct UID and title. Do not select the canonical dashboard UID or
replace its public share. No additional plugins, CSS or JavaScript are needed by
the visualizations. These files are deliberately outside the provisioned chart:
this is a temporary comparison, not a production TV rollout.

| File | Native visualization | Trade-off |
| --- | --- | --- |
| tmp-1.json | Horizontal Bar gauge, forced Top labels | Recommended first: fixes automatic left-label switching, preserves absolute values and full-width tracks. |
| tmp-2.json | Vertical Bar gauge | More vertical room for each bar; increasing node count eventually crowds labels horizontally. |
| tmp-3.json | Stat with names and colored absolute values | Minimal, readable values; sacrifices visual comparison of utilization. Colors still use each node's capacity and 75/90% thresholds. |
| tmp-4.json | Horizontal Bar gauge, Top labels, hidden values | Quietest bar comparison; absolute values require hover, a significant drawback for a television. |

All variants preserve every query, dynamic per-node capacity, missing-data
filter, sort order, threshold and panel rectangle. Only CPU, Memory and Disk
panels (21/22/23) change. No node names/counts are hardcoded. None can fit an
unbounded number of nodes legibly in a fixed TV rectangle: Top labels buys bar
width but each extra node still consumes height. Vertical bars consume width;
Stat also eventually needs more space. Check five nodes first, then synthetic
8/12-node frames in a separate preview before choosing a long-term layout.

## Research

- [Grafana Bar gauge](https://grafana.com/docs/grafana/latest/visualizations/panels-visualizations/visualizations/bar-gauge/): explicit Top/Left name placement, horizontal/vertical orientation, hidden value display and automatic sizing.
- Existing project design and source-specific normalization rationale: `docs/traffic-light-tv-design.md`.
- TV constraints and existing UID-scoped fit policy: `llm-wiki/android-tv.md`.

The underlying configuration issue is `namePlacement: auto`, not a requirement
for a custom plugin. TMP-1 is the smallest candidate change to promote after
rendered comparison. Documentation describes current Grafana; installed-version
rendering remains to be verified rather than inferred from JSON validation.
