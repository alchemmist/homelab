Для Pi нужен отдельный [ключ LiteLLM]({{< relref "ai/api.md" >}}). Учётная запись Open WebUI для API не используется.

В настройках пользовательского OpenAI-совместимого провайдера задайте:

| Поле | Значение |
| --- | --- |
| Base URL | `https://llm.alchemmist.xyz/v1` |
| API key | Ваш виртуальный ключ LiteLLM |
| Model ID | `qwen3.8-27b` |
| API | Chat Completions, если клиент предлагает выбор |
| Streaming | Включён |

Расположение и формат пользовательских провайдеров зависят от версии Pi. Используйте инструкцию установленной версии; не подменяйте ими настройки другого провайдера. После подключения сначала запросите короткий текст, затем проверьте один безопасный вызов инструмента в тестовом каталоге.

Инструменты Pi выполняются там, где запущен Pi, с выданными ему разрешениями. Они не используют Socrat Terminal автоматически. Поэтому работающий терминал в веб-чате не означает, что ваш локальный агент получил доступ к тому же каталогу.

Если короткий запрос работает, а длинный завершается по таймауту, проверьте собственный таймаут клиента и отправьте администратору время и текст ошибки. Не увеличивайте параллелизм, пытаясь ускорить очередь.
