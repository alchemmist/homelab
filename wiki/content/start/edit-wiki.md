---
title: Как редактировать wiki
weight: 10
---

Wiki публично доступна для чтения. Редактирование работает через **личный Authentik OIDC-вход и роль editor/administrator**, а не по принадлежности к сети. VPN и настройка DNS для редактора не нужны.

## Войти и получить права

Откройте [вход в wiki](https://wiki.socrat.alchemmist.xyz/login), завершите личный Authentik/MFA и вернитесь на нужную страницу. Если вы вошли, но карандаша нет, запросите editor у администратора. Reader может читать, но не публиковать. Общий Authentik-аккаунт и даже вход в другие панели эту роль не выдают.

Настройки аккаунта и личные MCP tokens находятся в `/admin`. Локальная форма восстановления предназначена владельцу, не обычному onboarding; чужие пароли/сеансы не используйте.

## Изменить и опубликовать заметку

Нажмите карандаш. Заголовок и Markdown можно редактировать прямо на странице; панель форматирования помогает со списками, ссылками, таблицами и кодом.

Черновик общий для изменений в текущей вкладке: можно переходить между страницами и менять структуру. Перед важной операцией сохраните отдельную копию текста; браузерный черновик не заменяет backup. Не начинайте параллельно редактировать те же страницы через UI и агента.

**Опубликовать** отправляет весь пакет. Сервер проверяет revisions, применяет patch, собирает Hugo и открывает принятый результат. После успеха текст доступен публичным читателям при reload. Коммит/синхронизация Git идут в фоне: публикация не ждёт GitHub Actions или Argo CD. **Отмена** отменяет неопубликованный пакет после подтверждения.

## Создать, переместить или удалить

Иконки над деревом создают заметку/папку; адрес — латиница, цифры и дефисы. Проверьте будущие URL и ссылки, затем опубликуйте. Перетаскивание меняет порядок/папку в том же черновике. Порядок и вложенность меняйте перетаскиванием в дереве: линия показывает позицию, подсветка — перенос внутрь папки. Изменения структуры публикуются вместе с текстом; проверьте URL и ссылки перед подтверждением.

Перед удалением найдите ссылки на страницу и согласуйте намеренное удаление; не оставляйте сломанные переходы. Секреты, личные конфиги, subscription URLs и внутренние receipts не публикуются: wiki читается без входа.

## Агент и MCP

Endpoint `https://wiki.socrat.alchemmist.xyz/mcp` использует **персональный token**, созданный в аккаунте, а не browser session/пароль Authentik. Для записи нужны write scope и native роль editor/admin; для чтения достаточно read scope. Храните token в защищённом хранилище клиента, не в Git/wiki/сообщении агенту. Перед update агент должен прочитать текущую revision, а при conflict — перечитать и согласовать изменения; перед delete нужна текущая tree revision.

## Если публикация не удалась

- **Нет карандаша / 403:** проверьте личность и native роль; подключение VPN не повышает права.
- **Login loop / MFA:** сохраните черновик, проверьте Authentik/session и сообщите администратору; не обходите проверки.
- **Conflict:** другой автор уже изменил страницу. Сохраните текст, прочитайте новую версию и объедините вручную. Не перезаписывайте её вслепую.
- **Build error:** предыдущая успешная публикация должна остаться доступной. Проверьте Markdown/ссылки и сохраните draft; не перезапускайте runtime ради повторной публикации.
- **Публичный текст обновился, Git ещё старый:** фоновый sync может отставать. Это не повод редактировать managed checkout на сервере или запускать конкурирующий Git writer.
