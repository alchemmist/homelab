Общий стартовый экран: [Socrat](https://socrat.alchemmist.xyz).

| Сервис | Для чего | Доступ |
| --- | --- | --- |
| [Open WebUI](https://chat.alchemmist.xyz) | Чат с локальной моделью, файлы и терминал | Публичный адрес; вход в личный аккаунт |
| [LiteLLM](https://llm.alchemmist.xyz/ui/) | Управление API-ключами и запросами | Публичный адрес; отдельные права в панели |
| [Блог](https://alchemmist.xyz) | Публикации автора | Открытое чтение |
| [Cats](https://cats.alchemmist.xyz) | Приложение Funny cats | Публичный веб-интерфейс |
| [LMS](https://lms.alchemmist.xyz) | Курсы, уроки и задания | Публичный веб-интерфейс; доступ к материалам проверяется в приложении |
| [Monori](https://monori.alchemmist.xyz) | Личные финансы | Отдельная авторизация для персональных данных |
| [Format Quorum](https://fq.alchemmist.xyz) | Форматирование кода | Публичный веб-интерфейс |
| [Статус](https://status.alchemmist.xyz) | Доступность сервисов | Публичная статусная страница |
| [Grafana](https://grafana.socrat.alchemmist.xyz/d/socrat-overview) | Метрики платформы | Через `socrat-wg`; просмотр без отдельного входа |
| [Umami](https://umami.alchemmist.xyz) | Аналитика сайтов | Отдельная учётная запись и права на сайт |

Административные инструменты описаны в [обзоре платформы]({{< relref "platform/overview.md" >}}). Приватные панели не требуют подключения пользовательского VPN: для них нужна именно [административная сеть]({{< relref "network/vpn.md" >}}).
